# sdd-merge-check-test

A test repository for the merge check in [sdd-skills](https://github.com/georgeracu/sdd-skills). `.github/workflows/sdd-work-item-check.yml` is an unchanged copy of `skills/setup/scaffold/workflows/sdd-work-item-check.yml`.

The pull requests here test it once passing and once failing. Nothing here is meant to merge.
